# Claude Code guidance

Read [AGENTS.md](AGENTS.md) first; it is the canonical repository router.
[PRODUCT.md](PRODUCT.md) and [STATUS.md](STATUS.md) define the current product
and evidence boundary.

For the installed plugin, invoke Skills through the
`/ai-booster-kit:<skill-id>` namespace described in
[docs/plugin.md](docs/plugin.md). Installation never starts a Skill and grants
no write or external authority.
